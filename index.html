Winner of Lewis & Clark College's ACM Hackaton in April 2023. Created with Carson Reader. A study tool built with React and SASS. Users upload an audio file (like a lecture recording). Then, using OpenAPI, they get a transcript and option for a summary or generated list of notes.

Another solo project that is a dupe of the game Snake. Expanded my knowledge of HTML, CSS, and JS. Used HTML canvas and allowed users to choose between several difficulties and color themes for the snake and buttons.
